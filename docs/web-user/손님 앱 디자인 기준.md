# 손님 앱 디자인 기준

손님 화면(`web-user`, 앱 "픽케이크"가 웹뷰로 감싼 화면)을 만들거나 고칠 때 이 문서를 먼저 본다.
값은 코드가 정본이다. 색·글자·모서리·움직임은 `packages/design-tokens`(`customerPreset`·`motionPreset`)에 있고, 부품은 `apps/web-user/src/common/components/`에 있다.
판매자 앱 기준(`docs/web-seller/판매자 앱 디자인 기준.md`)을 그대로 옮기지 않는다. 손님 앱은 지금 있는 부품과 모양에 맞추고 이상한 곳만 고친다(11-11 운영자). 화면을 검토하는 작업 방식은 skill `picake-app-review`에 있다.

## 먼저 지킬 것

1. **새로 꾸미지 말고 지금 있는 부품을 쓴다.** 그라데이션·AI 카드·그림으로 꾸민 칸은 쓰지 않는다(11-09 운영자 "촌스럽다"). 비슷한 부품을 먼저 찾는다(예: 고르는 칸은 검색 "정렬 및 필터" 창의 둥근 칸, 금액 범위는 같은 창의 가격 막대).
2. **진한 주황(`primary`)은 화면에 주 버튼 하나.** 고른 칸·배지는 연한 주황(`primary-50` 바탕 + `primary-100` 테두리 + 주황 글씨)을 써도 된다(판매자 앱과 다른 점).
3. **간격은 지금 앱 그대로:** 제목 아래 32, 항목 사이 24, 이름과 칸 사이 10, 칸 아래 안내 6(가입 화면·예약 창 기준). 화면 좌우 여백 20.
4. **색은 이름으로 쓴다.** `#FF653E`·`text-[#999]`처럼 값을 직접 적지 않는다. 카카오 노랑처럼 남의 상표 색만 예외다.

## 글자·모서리

- 글자: `text-2xs` 11(아래 탭) · `xs` 12(설명) · `2sm` 13 · `sm` 14(본문 작은 글) · `base` 16(본문·버튼) · `lg` 18 · `xl` 20(화면 제목) · `2xl` 24.
- 모서리: 버튼·입력 칸 12(`rounded-xl`), 카드 12~16, 아래 창 위쪽 24(`rounded-t-3xl`), 칩·동그라미 `rounded-full`.
- 버튼 높이: `Button` lg 52(기본)·md 48·sm 38. 모두 가로 가득이고 감싼 칸으로 폭을 정한다.

## 글

- **해요체**로 쓴다. 확인 창도 "…할까요?"(합니다체·"하시겠습니까?" 쓰지 않음). 서버 문구도 해요체(backend #65).
- **처리 뒤 안내는 한 일을 말한다**("예약을 취소했어요").
- **날짜**는 "11월 15일(일)", 올해가 아니면 해를 붙인다. 조사는 `josa.util`("을(를)" 그대로 쓰지 않기).
- **오류 안내에 영어 원문**("Request failed…", "Internal server error")을 보이지 않는다.

## 동작

- **누름 효과**(11-11 운영자 "작아지고 어두워짐", 두 앱 같음): 버튼·카드는 `press`(0.97배·조금 어둡게, 0.05초 늦게 시작해 스크롤과 구분), 줄 전체를 누르는 목록은 `press-bg`(회색 바탕). 버튼·링크 글자는 길게 눌러도 선택되지 않는다(`globals.css`, 상품 사진은 저장 가능).
- **아래 탭**: 보고 있는 탭을 다시 누르면 맨 위로(`scrollAppToTop`).
- **뒤로 가기**로 돌아오면 스크롤 자리 그대로(`useScrollRestoration()`을 목록 화면에 넣는다). 새로 들어오면 맨 위. 화면은 `#root-scroll-container` 안에서 스크롤한다.
- **움직임 값**은 공용(`duration-base`·`ease-enter`·`animate-sheet-in` 등)을 쓰고 `duration-200 ease-out`을 직접 적지 않는다. 아래 창은 올라올 때 300·닫힐 때 250, 확인 창은 커지며 나옴, 단계가 있는 화면은 `animate-step-in-forward|backward`. "동작 줄이기"를 켠 사람에게는 fade만.
- **밝은 화면만**: `color-scheme: only light`(layout `viewport`·globals.css). 휴대폰이 어두운 모드여도 바꾸지 않는다.
- **인증번호 칸**은 문자로 온 번호가 자판 위에 뜨게 `one-time-code`.

## 다시 꺼내지 않을 것 (운영자가 고르지 않음)

- 가게 없는 동네 "준비중" 창에서 견적 권하기(11-11)
- 시각 고르기 자정 "오전 12:00"(지금 "오전 00:00" 그대로)
- 위쪽 아이콘·길찾기·예약취소·예약상세 누르는 칸 넓히기, 입금 대기 "남은 시간 안에" 글
- 예약 취소·후기 쓰기 상품 카드가 하나일 때 가득 채우기
- 로딩 한 바퀴 800ms(1초 그대로), 로그인 화면 차례로 나타남
- 로딩 동그라미를 한 종류로 맞추기(목록 끝 "더 불러오는 중" 흰 동그라미 포함), 카카오 로그인 노랑을 공식 #FEE500으로(11-11 그림 보고 고르지 않음)

## 새 화면을 만들 때 확인

- [ ] 지금 있는 부품으로 만들었는가(그라데이션·꾸민 칸 없음)
- [ ] 진한 주황이 주 버튼 하나뿐인가
- [ ] 색·움직임을 값 대신 이름으로 썼는가
- [ ] 글이 해요체이고, 오류에 영어 원문이 없는가
- [ ] 못 불러오면 "다시 시도", 불러오는 동안 회색 뼈대인가
- [ ] 누르는 것에 `press`/`press-bg`가 있는가, 목록 화면이면 `useScrollRestoration()`을 넣었는가
- [ ] 360 폭에서 글·칩이 넘치지 않는가
- [ ] 화면 글·class를 바꿨으면 web-user e2e를 돌렸는가(`yarn web-user:test:e2e`)
