# 판매자 앱 디자인 기준

판매자 휴대폰 화면(판매자 앱 "픽케이크 사장님", 기획 I-48)을 만들거나 고칠 때 이 문서를 먼저 본다.
값은 코드가 정본이다. 색·글자·모서리는 `apps/web-seller/src/common/ui/tokens.ts`에 있다. 부품은 `common/ui/`에 있다. 모든 부품은 Storybook "판매자 앱/부품"(`AppUi.stories.tsx`)에서 볼 수 있다.
이 문서는 "어느 부품을 어떤 크기로 쓰는지"만 짧게 모은다. 2026-11-10 운영자 의견("인풋·버튼 높이, 이상한 위치, 너무 다른 스타일, 핑크색")으로 처음 정리했다.

## 먼저 지킬 것

1. **새로 그리지 말고 `common/ui` 부품을 쓴다.** 비슷한 것을 화면 안에서 직접 만들지 않는다. 없으면 `common/ui`에 부품으로 더하고 Storybook에도 넣는다.
2. **크기는 아래 표 값만 쓴다.** `h-[45px]`, `text-[15px]`처럼 표에 없는 값을 쓰지 않는다.
3. **색은 흰색, 회색(`ink-*`), 주황(`brand`) 셋뿐이다.**
   - 연한 주황 바탕과 흐린 주황(투명도)은 쓰지 않는다. 분홍으로 보인다.
   - 갈색·검정·빨강 버튼도 쓰지 않는다.
4. **휴대폰 기본 창이 앱 디자인과 너무 다르면 앱 창으로 바꾼다.** 날짜 고르기(`input type="date"`)가 그렇다.

## 색

| 이름        | 값      | 쓰는 곳                                                              |
| ----------- | ------- | -------------------------------------------------------------------- |
| `ink-900`   | #1F1F1E | 본문·제목                                                            |
| `ink-700`   | #4E4E4B | 칸 이름                                                              |
| `ink-600`   | #686864 | 보조·설명                                                            |
| `ink-500`   | #767672 | 예시 글씨(placeholder)                                               |
| `ink-400`   | #8C8C88 | 아이콘·꺼짐·못 누르는 글씨                                           |
| `ink-200`   | #D4D4D3 | 입력 칸·보조 버튼 테두리                                             |
| `ink-100`   | #EBEBEA | 나누는 선, 못 누르는 주 버튼 바탕                                    |
| `ink-50`    | #F5F5F5 | 회색 띠·검색 칸·아이콘 칸·빈칸·고른 줄                               |
| `brand`     | #FF653E | 주 버튼, 고른 칩·날짜, 할 일 아이콘, 경고 테두리                     |
| `brand-ink` | #B5401C | 작은 주황 글씨(배지·고칠 곳·경고·오늘 날짜). 버튼 글씨로는 쓰지 않음 |

- **주황은 뜻이 있는 곳에만 쓴다:** 고른 것, 할 일, 주 버튼.
- 고른 상태를 나타내는 방법은 셋 중 하나다.
  - 주황 채움 + 흰 글씨(칩·날짜)
  - 주황 테두리(카드형 선택)
  - 회색 바탕 + 주황 체크(목록 줄)
- 연한 주황 바탕(`#FFEFEB`)은 2026-11-10에 없앴다(`brand-tint` 값 없음).

## 글자

| 이름                      | 크기 | 쓰는 곳                          |
| ------------------------- | ---- | -------------------------------- |
| `text-title`              | 20   | 화면 제목(아래 탭 화면)·큰 숫자  |
| `text-heading`            | 18   | 창 제목·할 일 한 줄              |
| `text-group`              | 16   | 묶음 제목·빈 화면 제목           |
| `text-body`               | 15   | 본문·목록 이름·입력 글씨·큰 버튼 |
| `text-sub`                | 13   | 칸 이름·보조 정보·작은 버튼·칩   |
| `text-caption`            | 12   | 설명·도움말·고칠 곳 문구         |
| `text-badge` / `text-tab` | 11   | 배지 / 아래 탭·요일              |

- 굵기는 세 가지만 쓴다: `font-bold`, `font-semibold`, `font-normal`.
- 글은 해요체로 쓴다. "~합니다"가 아니라 "~해요"다(예: "이 기간에 집계된 주문이 없어요").

## 휴대폰 틀(MobileFrame) 안 PC 화면

상품 등록·수정, 피드, 스토어 정보·만들기는 아직 PC 화면 코드를 휴대폰 틀에 담아 쓴다.

- 틀 안에서는 PC 부품(`BaseButton`, `BaseInput`, `Textarea` 등)이 위 기준대로 그려진다.
- `globals.css`의 `.app-form`이 PC 색 이름(primary·accent 등)을 앱 색으로 바꾼다. 틀 안 `accent`는 회색이다.
- 새로 고칠 때는 `useInMobileFrame()`으로 틀 안을 나눈다. 틀 안 쪽은 `common/ui` 부품(`Chip`, `SelectInput` 등)을 쓴다.
- 아래 저장 줄은 `FrameSubmitBar`다(늘 화면 맨 아래). 버튼은 `FRAME_SUBMIT_BUTTON_CLASS`(48)를 쓴다.
- 고칠 곳이 있으면 "고칠 곳 n개"(보조) | 주 버튼(`flex-[2]`)으로 둔다.
- 고칠 곳·입력 중 모양은 앱 `Field`와 같다. 고칠 곳은 주황 테두리 1.5 + 아래 문구 12/600 #B5401C이고(`.app-form`이 `border-destructive`·`p.text-destructive`를 바꿈), 묶음 제목 색은 검정 그대로다. 입력 중은 진한 검정 테두리 1.5다. 고칠 곳 문구는 칸 이름과 같은 낱말로 쓴다(칸이 "종류"면 "종류를 골라 주세요").
- 틀 안 창(`Dialog`)도 앱 창처럼: 입력 칸은 `Textarea`·`BaseInput`, 칸 이름 13/700, 아래 버튼은 가득 찬 48(`FRAME_SUBMIT_BUTTON_CLASS`, 흰 보조 | 주황 주 버튼), 약한 행동은 회색 글자(`Button variant="quiet"`). 노란 강조 대신 #B5401C 굵은 글씨(예: AI로 쓰기 창).
- 밝은 화면만 쓴다: `color-scheme: only light`(globals.css·index.html). 휴대폰이 어두운 모드여도 웹뷰·브라우저가 강제로 어둡게 바꾸지 않는다.
- 마우스 올림(hover) 꾸밈은 마우스가 있는 기기에서만 나온다(tailwind `hoverOnlyWhenSupported`). 휴대폰에서 누른 버튼이 회색으로 남지 않게.
- 남은 일: 네이버 가져오기 창 안의 검토 표는 아직 PC 모양이 많다.

## 새 화면을 만들 때 확인

- [ ] 버튼·칸 높이가 48/40/36 중 하나인가
- [ ] 아래 버튼은 화면 맨 아래에 붙어 있는가(내용이 짧아도)
- [ ] 분홍(연한 주황 바탕·흐린 주황)이 없는가
- [ ] 휴대폰 기본 날짜 창 대신 `PickerButton` + `DateRangeSheet`를 썼는가
- [ ] 빈 화면이 남은 칸 가운데인가(`EmptyState big`)
- [ ] 글이 해요체인가
- [ ] 360 폭에서 글이 넘치거나 두 줄로 밀리지 않는가
- [ ] 새 부품을 만들었으면 Storybook에 넣었는가
